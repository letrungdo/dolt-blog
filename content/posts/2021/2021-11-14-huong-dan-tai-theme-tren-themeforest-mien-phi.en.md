ThemeForest is Envato's most diverse and highest-quality marketplace for buying and selling website themes and templates.
Some themes are offered for free there, but if you want beautiful and high-quality themes, you usually need to spend a decent amount of money.
If you desire beautiful and quality themes without spending money, this article will guide you through a trick to download themes currently being sold on ThemeForest for free.

## How to Download Free Themes on ThemeForest via GitHub

Currently, GitHub is the largest free Git source code repository.
It is understandable that many people choose GitHub to store web source code, and among those, many ThemeForest theme source codes are made public here.

### Step 1: Pick key phrases from the theme

Go to the demo page of the theme you selected, scroll down to the bottom of the page, where you will usually see a line like <b>Copyright © ...</b></br>
E.g., Copyright © 2021 letrungdo.com</br>
Copy the keyword "letrungdo.com"

### Step 2: Search ThemeForest from GitHub

Open https://github.com and paste the keyword from Step 1 into the search box and press Enter.</br>
Results will appear as shown below: https://github.com/search?q=letrungdo.com&type=code</br>
Many results will show up here; search through them and with a bit of luck, you'll find what you're looking for :v</br>

P.S.: You can try other related keywords from the demo page to get more results.
